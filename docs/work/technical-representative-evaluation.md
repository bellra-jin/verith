# Technical 대표 사례의 제한된 무키 평가

기준: PR81 merge `f1aedf123a7679798cd7158c22ead1d9c17de23b`.
이번 단위는 기존 보호 compiled graph/bridge 검사에 고정 사례를 추가한다. 별도 평가 실행기·
모델 호출·시세 조회·키/env 읽기·설치·DB·가격/가중치/정책 변경은 없다. 기존 실제 기록과
소진된 once 및 $1.30 보수 hold를 보존한다.

## 자료와 정답의 성격

기존 `test_technical_supervisor.py`의 DAILY/WEEKLY/MONTHLY는 생성된 합성 봉이다.
대표 사례도 이 날짜 fixture를 재사용한 합성 스트레스 입력이며 실제 거래일 달력이 아니다.
상위 W/M은 기존 고정 합성 자료이고, 일봉의 상승/하락/횡보/급락/저유동성 조건을 분리한다.

| 합성 사례 | 독립 입력 조건 | 기대 조건 |
|---|---|---|
| 상승 | 완만한 우상향 + 교대 진동, RSI 극단 방지 | 상승 추세 유지; MA/RSI/거래량/캔들 긍정, 저항 근접 부정; 가중합 .6 |
| 하락 | 연속 하락, 음봉, 아래꼬리 없음 | 하락 추세; RSI 극단 중립, 지지 근접 긍정과 구분; 가중합 -.4 |
| 횡보 | 가격 고정, 도지, 지지·저항 동시 근접 | 횡보·전체 중립; RSI 50, 가중합 0; 충분한 MA 이력 |
| 급락 | 고정 가격 뒤 마지막 봉 -40%, 음봉·아래꼬리 없음 | 반등 관찰로 오인하지 않고 하락 추세; 기존 산식은 가중합 -.4 |
| 저유동성 | 상승 입력과 동일한 가격, 거래량·거래대금만 기준 미만 | 방향 판단은 유지하되 low_liquidity 위험 포함 |

기대값은 입력 구성과 기존 우선순위·가중치에서 명시하며 제품 함수를 다시 호출한 값만을
정답으로 삼지 않는다. MA는 직접 평균과 대조하고 RSI의 중앙/극단/비극단 범위, 캔들 몸통과 방향,
저유동성 경계를 확인한다. 실제 graph 결과와 결정형 노드의 동일성 확인은 추가 연결 검사이다.
이것은 실현 수익률이나 전문가 라벨에 대한 정확도·오탐률 측정이 아니다.

관측 자료는 KIS 현대건설 000720의 기존 저장된 **1y 차트 일봉 245개**(2025-11-13~2026-11-13)에서
시장 필드만 추출했다. 채집일 2026-11-13, 봉 공개/종가 확정 시각은 미보고다. 날짜·OHLC·거래량·거래대금
투영의 canonical JSON SHA256은 `eedced5821cf1807b80e4feab49021c4ee6c986f5e1819a0632cf5797c641c6b`.
소유자/요청/승인 ID·키·토큰·모델 후보는 포함하지 않는다. 원래 전체 D/W/M 엔진 입력은 보존되지
않았으므로 이 차트 투영을 원 실행 전체의 완전한 재현이라고 하지 않는다. 관측 일봉의 유효성·직접 MA
평균·제한된 일봉 재생과 prefix 계산을 확인하며, 다른 네 시장 유형의 역사 자료가 있다고 주장하지 않는다.

## 설명과 시점 검사

실제 compiled graph와 가짜 LLM을 사용한다. 가짜 LLM은 현재 parser/validator를 통과한 코드 예시를
반환한다. 숫자·확정 signal·metrics·신뢰도가 바뀌지 않고 정상 설명과 부분 대체 계약이 유지되는지
확인한다. 반대 라벨·측정 숫자·매매 지시를 넣은 음성 사례도 거절되어야 한다. 실제 모델의 자연어 품질,
새 숫자 문법 전체나 모든 관계 의미를 검증했다는 뜻은 아니다.

동일 요청·동일 고정 입력의 graph 재실행 결과와 입력 불변을 검사한다. MA·RSI·캔들 계산은
뒤에 봉을 추가해도 기존 prefix가 바뀌지 않아야 한다. 이것을 fetcher의 미래정보 차단 증명으로
대신하지 않는다. 별도로 **실제 KIS range 제품 코드**에 날짜 초과 행을 반환하여 D/W/M 모두
조회 종료일 이후 날짜가 제거되는지 검사한다.

제한: 날짜 이하의 W/M 봉 값이 당시 완성된 집계였는지는 날짜만으로 알 수 없다. 표준 경로는
`as_of`를 조회 종료 날짜로 전달하고 날짜 범위를 거르지만, 공급자 공개 시각·당일 종가 확정·
역사적 데이터 vintage를 증명하지 않는다. 임의 주입 fetcher의 날짜/봉 내용도 자동 교정하지 않는다.
coverage.cutoff_validation은 계속 unverified다. 날짜가 맞는 진행 중 주·월봉을 임의로 완성봉으로
재분류하거나 일봉으로 보간하지 않는다. 시점 정합 정책 확대는 별도 근거가 필요하다.

## 결과

로컬 보호 graph는 **282 passed / guard 0**, 기존 self는 **9 passed**다. 이번 대표 평가 23개
(합성 graph 반복 5·지표 prefix 5·KIS cutoff 3·관측 재생 1·유동성 경계 4·패턴 anchor 5)를
포함하며 이전 259개 회귀를 유지했다. 다섯 사례의 국면·신호·수치·설명 계약에 새 불일치는
재현되지 않아 제품 계산/판정은 수정하지 않았다. 자료·검사·기록의 3파일만 변경한다.

저유동성은 두 평균 중 하나가 기준보다 작으면 켜지고 정확히 같은 경계에서는 켜지지 않는 것을
확인했다. 다섯 합성 형태에 컵앤핸들 후보가 생기지 않았고, 미래 봉을 붙여도 이전 시점의 박스/컵
탐지 결과는 같았다. 이는 이 형태들에 대한 제한된 음성 검사이며 패턴 탐지의 일반 정밀도·재현율을
산출한 것은 아니다. 실제 모델·다른 역사 시장 유형·실현 수익률 평가는 수행하지 않았다.

원격 CI의 기존 graph self와 로컬 전체 graph 실행은 구분한다. 새 일반 프레임워크나 guard 변경은
없다. 자기 검사 root는 정리됐으며 기존 실제 실행의 once/result/postflight와 hold는 불변이다.
정확한 PR head CI와 독립 검토 후 정상 게시·머지 결과는 별도 인계에 남긴다.
